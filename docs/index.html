⭐ What is AxisCLI?

AxisCLI is a modern Windows command-line interface built on the WinAPI. It focuses on speed, clarity, and simplicity — without the complexity of PowerShell or the limitations of CMD.

🔧 Core Features

• Lightweight & standalone (no dependencies)
• WinAPI native
• SYSTEM elevation support
• C/C++ plugin system (hot reload, custom directory)
• Hardware & network tools (hwinfo, getip, wifi, etc.)
• Script execution (.bat, .ps1, .vbs)
• Clean command structure
• Built-in help system

🧩 Plugin System

AxisCLI supports up to 64 plugins via native DLLs.

Set plugin directory:
plugin setdir C:\AxisPlugins

Reload plugins:
plugin reload

List plugins:
plugin list

Run plugin:
hello

Includes:
• axis.h (SDK)
• example_plugin.c
